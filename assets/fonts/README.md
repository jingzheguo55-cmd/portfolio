# 页面字体

- `monument-extended-regular.otf`：来自用户电脑已安装的 Monument Extended Regular，用于首页 `PORTFOLIO` 标题。官方页面：https://pangrampangram.com/products/monument-extended
- `monument-extended-ultrabold.otf`：保留的旧版字重文件，供历史预览版本使用。
- `pixelify-sans-variable.ttf`：来自 Google Fonts 官方仓库 https://github.com/google/fonts/tree/main/ofl/pixelifysans ，保留同目录的 `PixelifySans-OFL.txt`。
