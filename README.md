# 个人作品集预览

首页和作品展示采用深色效果预览：主背景 `#0A0A0A`，白色主文字、灰色辅助文字与细边框，详情使用 90% 不透明度的深色磨砂背景，文字与作品图保持完全不透明。简历页单独恢复原先 `#ebebeb` 浅灰背景和深色文字，导航、滚动条及浏览器主题色同步切换。主题覆盖样式集中在 `dark-theme.css`，不改变作品图片、个人照片或 PDF 原文件。

移动端优化集中在 `mobile.css`：导航及主要链接保留至少 44px 触控高度；首页采用可滚动的最小高度布局，头像姓名横排，避免矮屏下魔方与分类入口相互遮挡。作品列表缩减首屏动效留白，简历改善窄屏联系方式换行。手机项目详情增加吸顶返回入口、15px 正文与更宽的作品图，兼顾安全区和动态视口高度；桌面布局保持不变。

图片性能优化：88 张详情图从原始素材重新编码，保留全部原始像素尺寸，整体体积减少约 20%；字体配色页继续无损保存。26 张列表封面使用独立 640px 宽 WebP 缩略图，位于 `assets/previews/`，总体约 0.89MB，相比直接加载大图减少约 85%。54 张魔方图按实际展示尺寸导出为最长边 512px，个人照片显示 384px 宽 WebP，原 PNG 与 PDF 不修改。首页魔方和作品网格只在进入对应页面时初始化，后续大图懒加载；按静态资源体积估算，首页初始图片需求从约 7.2MB 降至 0.95MB，不代表固定加载耗时。

网站实际引用的图片统一为 WebP，包括标志 `assets/butterfly-mark.webp`（240×200 无损，供高分屏使用）和 `assets/favicon.webp`（64×64 无损）。原始 SVG、PNG 仅作为源文件保留，不由页面加载；已优化的作品图不再重复有损重编码。

线上发布沿用 GitHub 仓库连接的 Vercel `portfolio` 项目，推送 `main` 后由原有 Vercel 集成自动部署；GitHub Pages 也保留原有自动发布，不另建项目。

运行 `node preview-server.mjs`，打开 `http://127.0.0.1:4173/`。

首页按用户提供的 1920×1050 设计图还原：浅灰背景 `#ebebeb`、左上蝴蝶点阵标志与 `jingjing.guo` 字标、顶部中文导航、左侧照片及姓名、右侧六项作品入口，以及底部裁切的超大 `PORTFOLIO`。首页不显示邮箱电话。

最新微调：移除橙色“三”；照片使用用户新上传的原图 `assets/profile-original.png`（未进行 AI 处理）；底部使用 Monument Extended Regular，放大的 Logo 字标使用 Pixelify Sans。字体文件位于 `assets/fonts/`，来源与授权文件见该目录。桌面导航 17px、姓名区 27px、项目列表默认 26px、悬停 32px；魔方各面间距与九宫格间距联动，保持多轴旋转。

魔方包含 54 张本地图片，支持多轴自动旋转、拖动和悬停慢转。悬停或键盘聚焦分类时，随机点亮 9 个可见格子，不重复地展示该分类的 9 张图片；旋转时将移出视野的图片转移到其他可见格子，退出预览后恢复原图。Archive 和项目图片预览可以正常访问。

魔方稳定性：旋转角度连续累加，不在每圈结束时回绕；切换页面、恢复前台和窗口重新获得焦点时重置帧计时，避免补算暂停时间。默认格子使用固定的 3D 变换，不启用无效果的滤镜；分类预览滤镜仅作用于图片，保持格子的背面裁剪与深度层级稳定。

本地 `versions/` 保存历史设计预览，不上传到发布仓库。

网站为纯静态 HTML、CSS、JavaScript，无构建步骤。GitHub Pages 发布设置使用 `main` 分支的根目录 `/`，`.nojekyll` 用于直接发布静态文件。图片和字体均使用相对路径，支持 `/portfolio/` 子目录访问。

简历动效：进入 `#about` 时，姓名、个人优势和照片错峰淡入上移；专业能力、工作经历和教育背景进入视野后轻柔渐显，同次浏览不重复播放。采用 IntersectionObserver 和透明度 / 位移动画，不接管滚轮或模拟滚动。切换页面时清理观察器，重新进入简历时重播；系统启用“减少动态效果”或浏览器不支持观察器时直接显示内容。

作品展示顶部欢迎动效采用最小加加速度的五次位移曲线：缓起加速、惯性滑行、柔和减速，并在周期衔接处短暂缓停，速度与加速度连续归零。波浪幅度随速度变化，文字与插图的倾斜采用阻尼弹簧跟随加速度，插图的倾斜响应略强；不同刷新率下按时间推进，缩放时保留周期进度，暂停与恢复不会跳帧。

当前 54 张作品图片使用用户提供的个人素材，按原文件编号每九张依次对应六个分类，位于 `assets/cube-personal/`。图片转换为 WebP，最长边不超过 960px，不放大小图；原始 PNG 文件保留在用户素材目录。

“我的简历”页面位于 `#about`，按用户提供的简历整理个人简介、三项专业能力、四段工作经历、两段教育背景与联系方式。采用黑白灰、细分隔线和留白排版，内容横向撑满、左右各保留 24px，移除英文翻译装饰，正文与段落间距放大。照片使用本次提供的原图 `assets/resume-portrait.png`，仅小幅辅助展示，不修改首页照片。独立样式位于 `resume.css`，桌面双栏履历、手机单栏阅读；邮箱和电话可点击，底部入口可返回作品展示页。页面右上方提供 PDF 下载，`assets/resume-guojingjing.pdf` 为用户 `jianli` 文件夹内原文件的完整副本，下载文件名为 `郭晶晶UIUX简历1020.pdf`。

作品展示页 `#archive` 沿用首页浅灰背景，顶部加入参考 Effect 104 公开演示重做的波浪文字跑马灯，内容为 `Welcome to my UI/UX portfolio.`，文字间依次穿插用户提供的 `43`、`4`、`40` 三张素材，资源位于 `assets/archive-welcome/`，增加动效上下留白。动效由 `archive-welcome.js` 使用逐字位移和切线旋转实现，不依赖外部动画服务；可手动暂停，离开视野、切换页面或后台时停止更新，减少动态效果设置下显示完整静态欢迎语。项目顺序为仰膳净菜、农惠通、Emerson、产教融合教育云平台、运营视觉、品牌网页和其他设计，详情的下一个项目遵循相同顺序，首页魔方分类顺序不变。桌面每行七张，各项目分别展示 4、5、4、5、4、3 张预览图；图片按原始宽高比完整显示，每行顶部对齐、底部自然错落。项目名称约 11–14px、编号 12px，均保持单行，极窄时省略并可悬停查看全名。网格左右各留 12px，所有设备列间距均为 12px，桌面行间距 56px；平板四列、手机两列并相应调整行间距。悬停或聚焦任意图片时，同项目预览一起高亮，其他项目淡出，跨行保持联动。

开合动效由 `paper-transition.js` 与 `paper-renderer.js` 实现：预览图与详情中的同一张图片按编号配对，以轻量原生 WebGL 网格绘制软纸形变，边角带有先后顺序，纸面轻微弯曲和明暗变化，而非整张卡片旋转。打开和关闭的整组动效均为 1 秒，已计入图片间的轻微错峰，文字和遮罩也在 1 秒内完成；保留缓起、舒展、柔和落定的连续运动，关闭时反向收回各自的网格位置。不依赖外部动画库，WebGL 不可用时退回平滑的 DOM 转场。关闭前保留当前图集滚动位置，连续开关、切换项目和窗口缩放会清理动画与显卡资源；系统开启“减少动态效果”时直接显示或关闭。现有素材预设真实宽高，避免图片延迟加载造成转场目标跳位。
