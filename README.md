# 个人作品集预览

运行 `node preview-server.mjs`，打开 `http://127.0.0.1:4173/`。

首页按用户提供的 1920×1050 设计图还原：浅灰背景 `#ebebeb`、左上蝴蝶点阵标志与 `jingjing.guo` 字标、顶部中文导航、左侧照片及姓名、右侧六项作品入口，以及底部裁切的超大 `PORTFOLIO`。首页不显示邮箱电话。

最新微调：移除橙色“三”；照片使用用户新上传的原图 `assets/profile-original.png`（未进行 AI 处理）；底部使用 Monument Extended Regular，放大的 Logo 字标使用 Pixelify Sans。字体文件位于 `assets/fonts/`，来源与授权文件见该目录。桌面导航 17px、姓名区 27px、项目列表默认 26px、悬停 32px；魔方各面间距与九宫格间距联动，保持多轴旋转。

魔方包含 54 张本地图片，支持多轴自动旋转、拖动和悬停慢转。悬停或键盘聚焦分类时，随机点亮 9 个可见格子，不重复地展示该分类的 9 张图片；旋转时将移出视野的图片转移到其他可见格子，退出预览后恢复原图。Archive 和项目图片预览可以正常访问。

本地 `versions/` 保存历史设计预览，不上传到发布仓库。

网站为纯静态 HTML、CSS、JavaScript，无构建步骤。GitHub Pages 发布设置使用 `main` 分支的根目录 `/`，`.nojekyll` 用于直接发布静态文件。图片和字体均使用相对路径，支持 `/portfolio/` 子目录访问。

当前 54 张作品图片使用用户提供的个人素材，按原文件编号每九张依次对应六个分类，位于 `assets/cube-personal/`。图片转换为 WebP，最长边不超过 960px，不放大小图；原始 PNG 文件保留在用户素材目录。邮箱与电话仍为示例值。

作品展示页 `#archive` 参考 Gil Huybrecht 作品集的连续项目图片网格，沿用首页浅灰背景。顶部仅保留全站主导航，移除页内标题、说明和分类 tabs，直接展示作品网格。桌面每行七张，六个项目分别展示 5、5、4、6、4、6 张预览图；悬停或聚焦任意图片时，同项目全部预览一起高亮，其他项目淡出，跨行也保持联动。平板适配四列、手机适配两列。

点击预览图打开 `#work/项目标识` 对应的原生对话框，网格保留在模糊遮罩后方；左侧固定项目介绍和设计方向，右侧独立纵向滚动展示该项目全部图片。手机详情改为上下布局。支持关闭按钮、Escape、点击遮罩退出和下一个项目切换，关闭后保留列表滚动位置。项目介绍暂用对应领域的示例文案，可在项目数据中补充正式内容。

开合动效由 `paper-transition.js` 与 `paper-renderer.js` 实现：预览图与详情中的同一张图片按编号配对，以轻量原生 WebGL 网格绘制软纸形变，边角带有先后顺序，纸面轻微弯曲和明暗变化，而非整张卡片旋转。打开和关闭的整组动效均为 1 秒，已计入图片间的轻微错峰，文字和遮罩也在 1 秒内完成；保留缓起、舒展、柔和落定的连续运动，关闭时反向收回各自的网格位置。不依赖外部动画库，WebGL 不可用时退回平滑的 DOM 转场。关闭前保留当前图集滚动位置，连续开关、切换项目和窗口缩放会清理动画与显卡资源；系统开启“减少动态效果”时直接显示或关闭。现有素材预设真实宽高，避免图片延迟加载造成转场目标跳位。

目前项目详情沿用现有魔方素材作为效果预览。后续可在 `script.js` 的对应项目中新增 `galleryPictures` 数组，填入任意数量的本地图片相对路径；可用 `previewPictures` 单独指定 4–6 张网格预览图，并用 `description`、`services`、`platform` 设置正式介绍。首页魔方仍使用原 `pictures` 编号。画廊样式单独放在 `gallery.css`，不影响主页样式。
